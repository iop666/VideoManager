# images/ — README 插图目录

本目录存放仓库根 `README.md` 引用的图片，方便在任何子页面里用相对路径 `images/xxx.png` 展示。

## 使用规则

1. 图片放入本目录，推荐 **PNG / JPG**，宽度约 **800–1200px**、单张 **≤ 1MB**；
2. README 中引用格式：`![说明文字](images/你的文件名.png)`；
3. README 全文已按章节预留 `<!-- 📷 插图位：… -->` 注释，把对应注释替换成图片链接即可；
4. 命名建议：`01-two-worlds.png`、`02-import.png` 这类有序命名，方便对照。
